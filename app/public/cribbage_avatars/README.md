# VABGames Cribbage Player Avatars

Twelve selectable multiplayer player icons in a coordinated vintage card-room style.

## Contents

- `web-256/` contains the twelve optimized 256×256 website avatars.

The multi-megabyte source artwork remains preserved in the original project
history. This application repository tracks only the optimized runtime assets
that it actually serves.

## Recommended selection order

Display the avatars as a responsive four-column grid in this order:

1. Male 01–04
2. Female 01–04
3. Fox, Owl, Dog, Cat

## UI guidance

- Display at 64–96 CSS pixels in the join dialog.
- Use `border-radius: 50%` for circular presentation.
- Add a 3 px antique-gold ring to the selected avatar.
- Keep the source images square; apply the circle in CSS rather than modifying the files.
- Store the selected filename or a stable avatar ID with the player's lobby profile.

Generated with the built-in image-generation workflow.
